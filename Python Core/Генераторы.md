# Генераторы

Генератор — это функция, которая создаёт последовательность значений по одному за раз, подобно итератору, и сохраняет своё состояние между вызовами.   

При каждом вызове генератора выполнение функции приостанавливается на месте, где был вызван yield, возвращая значение и сохраняя текущее состояние (все локальные переменные и положение в коде). При следующем вызове генератора выполнение продолжается с того же места.    
Когда выполнение доходит до конца генератора, объект генератор возбуждает исключение StopIteration. 

Обычная функция, в отличие от генератора, при каждом вызове выполняется полностью, от начала до конца, и не сохраняет своё состояние после завершения. При последующем вызове функции выделяется новое место в памяти, и она начинает свою работу заново, начиная с первой строки кода, вплоть до выполнения return (или достижения конца функции), после чего её состояние полностью теряется.

#

Работа с генератором происходит по стандартным сценариям работы с итератором:

* вызывать функцию next() для получения очередного значения генератора
* итерироваться с помощью цикла for по генератору
* распаковывать генератор
* проверять принадлежность с помощью оператора in


Функция генератор возвращает объект специального типа <class 'generator'>, который реализует протокол итератора, то есть является самым настоящим итератором.

#
Основные особенности, присущие всем функциям генераторам:

- Любая функция, содержащая ключевое слово yield, является функцией генератором
- Когда вызывается функция генератор, то она не возвращает единственное значение, как это делает обыкновенная функция
- Функция генератор всегда возвращает объект типа generator, который поддерживает протокол итератора
- Разница между yield и оператором return заключается в том, что для ключевого слова yield состояние выполнения генератора приостанавливается и локальные переменные сохраняются. При следующем вызове метода генератора __next__() функция возобновляет свое выполнение из той точки, из которой завершила в прошлый раз.

Генератор является итератором, поэтому он обладает всеми его особенностями:

- Нельзя получить длину генератора функцией len()
- Нельзя распечатать элементы генератора функцией print() без предварительной распаковки
- У генератора нельзя получить элемент по индексу
- После итерации по генератору он становится пустым
#

Класс Генератора внутри:

```
class GenerateInts:                             
    def __init__(self, n):         # конструктор принимает верхнюю границу диапазона
        self.n = n
        self.current = 0
    
    def __iter__(self):
        return self
    
    def __next__(self): 
        if self.current == self.n:
            raise StopIteration
        else:
            self.current += 1
            return self.current - 1
```
<details>
  <summary>Генераторы с побочными действиями</summary>

`[Побочные действия]` (side effects) в генераторах — это изменения состояния программы, которые происходят в процессе выполнения генератора, но не связаны напрямую с возвращаемыми значениями через yield. Эти побочные действия могут включать в себя запись данных в файл, изменение глобальных переменных, отправку запросов в сеть, работу с базами данных и многое другое.

<details>
  <summary>Детально</summary>

1. Пример побочного действия: Представим генератор, который читает строки из файла и одновременно ведет логгирование того, сколько строк было прочитано:

```
def file_reader_with_logging(file_name):
    count = 0
    with open(file_name, 'r') as file:
        for line in file:
            count += 1
            print(f"Прочитана строка {count}: {line.strip()}")
            yield line.strip()
```
В этом примере побочным действием является вывод на экран информации о количестве прочитанных строк. Хотя основной задачей генератора является возврат строк из файла, он также выполняет и побочную задачу — логгирование.  

2. Сохранение состояния и побочные действия: Поскольку генераторы сохраняют состояние между вызовами, побочные действия будут выполняться последовательно, каждый раз, когда вызывается next(). Это означает, что побочные действия будут происходить только тогда, когда генератор продолжает своё выполнение.  

Например, если в приведённом выше генераторе остановить итерацию после нескольких строк, то последующие побочные действия (логгирование остальных строк) не будут выполнены.  

3. Влияние на повторное использование генераторов: Если генератор имеет побочные действия, нужно быть осторожным с повторным использованием одного и того же генератора. После завершения генератора его нельзя "перезапустить" с тем же состоянием, потому что его выполнение закончено. Попытка повторного использования может привести к непредвиденным последствиям.
Пример:
```
gen = file_reader_with_logging('example.txt')

# Прочитаем одну строку
next(gen)

# В этом месте логгирование уже произойдет для одной строки.
# Если попробовать снова начать итерацию, генератор продолжит с того места, где остановился.
```

4. Возможные проблемы:
* Непредсказуемость: Если генератор используется в разных контекстах, побочные действия могут привести к неожиданным результатам, если не учитывать, когда и где они происходят.
* Трудности отладки: Из-за сохранения состояния между вызовами и возможных побочных действий может быть сложно отследить, что именно происходит в генераторе.  

5. Управление побочными действиями:
* Явное управление состоянием: Если генератор выполняет сложные задачи с побочными эффектами, может быть полезно явно управлять состоянием (например, через передаваемые параметры или использование специальных флагов).
* Изоляция побочных действий: Рекомендуется минимизировать побочные действия внутри генераторов, если это возможно, чтобы генератор оставался более предсказуемым и легче управляемым.

<details>
  <summary>Пример генератора с записью данных в файл</summary>

Представим, что у нас есть генератор, который обрабатывает данные и записывает результаты обработки в файл на каждой итерации.
```
def process_and_log_to_file(data_list, log_file):
    with open(log_file, 'a') as file:
        for data in data_list:
            # Обработка данных (например, умножение на 2)
            result = data * 2
            
            # Побочный эффект: запись в файл
            file.write(f"Processed data: {data}, Result: {result}\n")
            
            # Возвращаем результат
            yield result

# Используем генератор
gen = process_and_log_to_file([1, 2, 3, 4], 'log.txt')

for item in gen:
    print(f"Результат: {item}")
```
Что происходит в этом примере:
1. Открытие файла: Файл log.txt открывается в режиме append ('a'), чтобы добавлять данные в конец файла без перезаписи уже существующего содержимого.
2. Обработка данных: На каждой итерации генератор умножает текущее значение на 2 и сохраняет результат в переменной result.
3. Запись в файл: После обработки данных генератор записывает исходное значение и результат в файл. Это и есть побочный эффект.
4. Возврат результата: Генератор возвращает результат обработки (result) через yield.

Важно помнить:
* Порядок выполнения: Запись в файл происходит до того, как генератор возвращает результат. Это означает, что при каждой итерации сначала будет записано в файл, а затем возвращено значение.
* Управление ресурсами: В примере используется контекстный менеджер (with open(...) as file:), чтобы гарантировать, что файл будет закрыт корректно после завершения работы генератора.

<details>
  <summary> return в теле функции генератора</summary>

- Функция-генератор выполняется и возвращает значения через yield до тех пор, пока не встретит ключевое слово return.
- Как только генератор встречает return, он сразу же прекращает свою работу.
- В этот момент возникает исключение StopIteration, которое сигнализирует о том, что генератор больше не будет возвращать новые значения и итерация завершена.
- Значение  идущее сразу после ключевого слова `return` не возвращается. `return` просто останавливает работу функции. 

```
def generate_ints():
    yield 1
    yield 2
    return 3
    yield 4

for num in generate_ints():
    print(num)
```
Выведет:
```
1
2
```
